## Repository files

- `.gitignore` excludes common dependency folders, build outputs, caches, logs, local environment files, and editor/OS artifacts.
- `.gitattributes` normalizes text files and marks common binary assets.
- `.editorconfig` keeps whitespace and line endings consistent across editors.
- `AGENTS.md` gives future coding agents working instructions for this repository.
- `.cursor/rules/repository-context.mdc` points Cursor agents to the maintained context docs.
- `docs/agent-context.md` preserves setup, architecture, and verification context as the project grows.
- `.github/pull_request_template.md` provides a consistent checklist for changes.
